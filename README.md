# Datavault Insight Stream

Datavault Insight Stream is a next.js and fastapi-powered analytical SaaS tool designed for real-time data visualization and insights. It enables businesses to easily access, analyze, and visualize their data in real-time, improving data-driven decision-making.

## Tech Stack
- Next.js
- FastAPI
- TypeScript

## Setup Instructions
1. Clone the repository:
	`git clone <repository-url>`
2. Navigate into the project directory:
	`cd datavault-insight-stream`
3. Install dependencies:
	`npm install`
4. Run the development server:
	`npm run dev`

## Environment Variables
- `DATABASE_URL` - The URL to the data source
- `API_KEY` - The API key for external services
